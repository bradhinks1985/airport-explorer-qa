Welcome to the Airport and City Explorer App!

This is an app to explore airports and cities from around the world.
Pages are organized by airport or city features.
See below for features and page instructions.

Page Features
  • Airport Info:
    • View details for an airport in the world.
    • Details include: latitude, longitude, temperature.
    • View details for random airport.
    • View an AI generated summary of the airport
    • Open a google search for the airport
    • Open the Wikipedia page for the airport
    • View the airport on a world map

  • Airport Map:
    • View all world's airport on a map.
    • View details of an airport.

  • Airport List:
    • View a list of airports for a country.
    • View an AI generated summary of the airport.
    • Open a google search for the airport.

  • City Info:
    • View details for a selected city in the world.
    • Generate details for random city.
    • Details include: population, latitude, longitude, sunrise and sunset times.
    • View an AI generated summary of the airport.
    • Open a google search for the airport.
    • Open the Wikipedia page for the airport.
    • View the airport on a world map.
    • View a list of cities for a country, including AI summary and google search.

  • City Map:
    • View all world's cities on a map.
    • View details of a city.

  • Similar Latitude Cities:
    • View cities within a specified latitude range of a city.
    • View cities on a map.

  • Latitude Rank Cities:
    • View a country's cities with >100k population, ranked by latitude.

  • Cities in Latitude Range:
    • View cities within latitude range of selected latitude.

  • City Distances:
    • Calculate the distance between two cities.

Airport Info page instructions
  • Filter first by country, then select or type to find an airport.
  • Once an airport is selected, airport data will display.
  • Generate Random Airport: displays details about a random airport.
  • View AI Summary: displays AI generated airport summary.
  • Search Google: opens Google search of airport.
  • View Wikipedia page: opens Wikipedia page of airport.
  • View on Map: displays airport on world map.
  • Busiest Routes and Airlines and Destinations data is sourced from current airport Wikipedia page.
  • Busiest Routes displays passenger volume for prior year.

Airport Map page instructions
  • Zoom in or click on cluster circles to view an airport.
  • View Airport Info: links to Airport Info page for that airport.

Airport List page instructions
  • Select country to view all airports.
  • AI Summary: displays AI generated summary of airport.
  • Google: opens a Google search of the airport.

City Info page instructions
  • Filter first by country, then select or type to find a city.
  • Once Select City is clicked, city info will display.
  • Get Random City Info: displays info for random city.
  • After country is selected, will display.
  • Info for All Cities of Selected Country: displays all cities for country.
  • All cities table has AI Summary and Google.
  • View AI Summary: displays AI generated summary of city.
  • Search Google: opens Google search for city.
  • View Wikipedia page: opens Wikipedia page for city.
  • View City on Map: displays city on world map.

City Map page instructions
  • Zoom in or click on cluster circles to view an airport.
  • View City Info: links to Airport Info page for that airport.

Similar Latitude Cities page instructions
  • Select country. Then select or type to find city.
  • Enter latitude range from 0-5 degrees.
  • After Find Cities is clicked a list of cities with >100k population within the latitude range will display.

Latitude Rank Cities page instructions
  • Select country, then list of cities >100k population will display.

Cities in Latitude Range page instructions
  • Select latitude and latitude range.
  • After Find Cities is clicked, cities >10k population within latitude range will display.

City Distances page instructions
  • Select or type to find two cities.
  • Calculate Distance will display the miles between the cities.
